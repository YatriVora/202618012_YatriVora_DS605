## Project Details

This assignment is split into two parts:

- **Part A — NumPy:** vectorized array operations, statistics, indexing/slicing on 2D and 3D
  arrays, matrix arithmetic and linear algebra (transpose, determinant, inverse), and sampling
  from a normal distribution with a histogram — all implemented using NumPy's `Generator` API
  (`np.random.default_rng`) for reproducibility.
- **Part B — Pandas:** loading and inspecting the Titanic dataset, boolean filtering and
  querying, `groupby()` aggregations, missing-value analysis and imputation (mean, median,
  mode, random), Fare outlier detection via IQR, feature engineering (`FamilySize`, `IsAlone`),
  a pivot table of survival rate by Sex and Pclass, and visualizations (correlation heatmap,
  survival rate by sex, Age vs Fare scatter).
